# 레이저 장기: 클래스 아레나

한 대의 태블릿에서 두 학생이 대전하고, 경기 시작·연결 상태·종료 결과만 교사 호스트에 전달하는 백엔드리스 학급용 게임입니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

GitHub에 업로드한 뒤 Vercel에서 프로젝트를 가져오면 됩니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다.

## 접속 흐름

1. 교사가 메인 화면에서 `교사 운영 페이지`에 접속합니다.
2. 과학 또는 수학 교과 인트로를 진행하거나 `건너뛰기`로 바로 운영 화면에 들어갑니다.
3. 학생 명단을 줄바꿈으로 입력한 뒤 `플레이어 등록`을 눌러 명단을 확정합니다.
4. 확정 명단 아래의 `게임 시작`을 눌러 학생 경기장 접속을 활성화합니다.
5. 학생 태블릿에서 QR을 읽거나 숫자 4자리 코드를 입력하고 경기장 번호를 선택합니다.
6. 이름 카드 그리드에서 두 학생을 청색·적색으로 선택하면 호스트가 중복 참가 여부를 검사합니다.
7. 경기 시작 후 모든 말 이동과 레이저 계산은 태블릿 로컬에서 처리됩니다.
8. 왕이 제거되면 승자·패자·경기 시간·턴 수가 호스트에 전송되고 전광판에 반영됩니다.
9. `게임 종료(결과 공개)`를 누르면 진행 중인 경기는 제외되고, 완료된 경기 기준의 최종 순위표와 축하 애니메이션이 표시됩니다.
10. 결과 공개 화면의 `게임 결과 복사하기`를 누르고 한셀·엑셀에 붙여넣어 최종 순위를 저장합니다.

## 데이터 정책

- 데이터베이스가 없습니다.
- 교사 기록은 `sessionStorage`에만 임시 저장되며 별도의 장기 저장·백업파일 기능을 제공하지 않습니다.
- 학생 게임판은 새로고침 복구를 위해 해당 태블릿의 `localStorage`에만 저장됩니다.
- PeerJS 공용 시그널링은 연결 수립에만 사용하며 경기 기록을 저장하지 않습니다.
- 최종 순위표 복사 내용은 탭으로 구분되어 한셀·엑셀의 각 열에 자동으로 나뉩니다.

## 이미지·효과음·BGM

- 버튼, 확인, 오류, 말 선택·이동·회전, 경기 시작, 레이저, 반사, 분리, 말 제거, 왕 피격, 승리, 결과 전송 효과음 14개가 `public/audio`에 포함되어 있습니다.
- 첨부 에셋의 레이저 발사·스플리터·승리 효과음이 적용되었고, 나머지 효과음은 `scripts/generate-sfx.mjs`로 다시 생성할 수 있습니다.
- 첨부된 운영용 BGM이 `public/audio/host-bgm.mp3`에 포함되어 있으며 운영 시작 시 재생되고 운영 종료 시 정지합니다.
- 모든 화면 우측 하단의 작은 BGM 제어 창에서 재생·일시정지·볼륨을 조절할 수 있습니다.
- 청색·적색 각 5종의 실제 플레이용 탑뷰 말 이미지가 이동과 90도 회전에 연결되어 있습니다.
- 연습 경기에서는 장기판 바깥쪽에 양쪽 방향의 `연습 경기` 안내가 표시되고, 각 플레이어 정보 영역에서 메인화면으로 이동할 수 있습니다.
- 메인 화면의 `게임 설명서`는 목표·규칙·교사 운영 순서·영상 검색 안내를 4장 슬라이드로 제공합니다.
- 교사 페이지 진입 인트로에서는 화면을 뒤집지 않고 과학의 직진·반사 답을 바로 공개하거나, 수학의 밀기·좌우 선대칭 뒤집기·좌우 90도 굴리기를 직접 확인할 수 있습니다. 마무리 문구는 긴장감 있는 글꼴로 한 줄씩 순차 공개됩니다.
- 레이저 말 내부에는 현재 발사 방향을 알려주는 화살표가 계속 표시됩니다.
- 승리 왕관과 경기장·호스트·결과·전광판 배경이 화면별로 적용되어 있습니다.
- 이미지와 음원 교체용 프롬프트는 `ASSET_PROMPTS.md`에 있습니다.

## 규칙 구현 메모

- 게임판은 모든 칸이 정사각형인 8×8 정사각형입니다.
- 장기판 좌우에는 서로 마주 보는 두 플레이어 전용 정보 패널이 있으며, 게임 시간·현재 전적·클릭형 말 기능 도움말·제거된 말을 표시합니다. 별도의 바깥쪽 말 기능 패널은 사용하지 않습니다.
- 말을 선택하면 실제로 이동할 수 있는 인접 빈칸에 파란색 글로우 점이 표시됩니다.
- 경기 중 `게임 종료`를 누르면 확인 창이 나타나며, 취소된 경기는 전적과 최종 순위에 포함되지 않습니다.
- 자신의 차례에 자기 말 하나를 8방향으로 한 칸 이동하거나 90도 회전합니다.
- 레이저는 이동할 수 없고, 판 바깥을 향하도록 회전할 수 없습니다.
- 행동 확정 후 자기 레이저가 자동 발사됩니다.
- 스플리터는 직진 레이저를 유지하면서 대각선 면을 따라 90도 반사 경로를 하나 추가합니다.
- 왕은 어느 방향에서 맞아도 제거됩니다.
- 세모기사는 대각선 거울면에서 바깥쪽으로 90도 반사하고, 비거울면에서 맞으면 제거됩니다.
- 네모기사는 색상 거울면에서 레이저를 180도 되돌리며, 나머지 세 면에서 맞으면 제거됩니다.

초기 배치는 사용자가 제공한 8×8 기준 이미지에 맞춰 밝은색 진영을 적색 플레이어에, 어두운색 진영을 청색 플레이어에 대응시켰습니다. 위치뿐 아니라 레이저 발사구와 각 거울면의 방향도 함께 반영했습니다.
