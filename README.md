# 레이저 장기: 클래스 아레나

한 대의 태블릿에서 두 학생이 대전하고, 경기 시작·연결 상태·종료 결과만 교사 호스트에 전달하는 백엔드리스 학급용 게임입니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

GitHub에 업로드한 뒤 Vercel에서 프로젝트를 가져오면 됩니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다.

## 접속 흐름

1. 교사가 메인 화면에서 `교사 운영 페이지`에 접속합니다.
2. 학생 명단을 줄바꿈으로 등록하고 운영을 시작합니다.
3. 학생 태블릿에서 QR을 읽고 경기장 번호를 선택합니다.
4. 두 학생이 이름을 선택하면 호스트가 중복 참가 여부를 검사합니다.
5. 경기 시작 후 모든 말 이동과 레이저 계산은 태블릿 로컬에서 처리됩니다.
6. 왕이 제거되면 승자·패자·경기 시간·턴 수가 호스트에 전송되고 전광판에 반영됩니다.
7. 운영 종료 후 CSV 또는 JSON 로그를 다운로드하고 기록을 완전히 삭제합니다.

## 데이터 정책

- 데이터베이스가 없습니다.
- 교사 기록은 `sessionStorage`에만 임시 저장되어 탭을 닫으면 사라집니다.
- 학생 게임판은 새로고침 복구를 위해 해당 태블릿의 `localStorage`에만 저장됩니다.
- PeerJS 공용 시그널링은 연결 수립에만 사용하며 경기 기록을 저장하지 않습니다.

## 에셋 교체

현재 버전은 CSS 게임 말과 합성 효과음을 사용하므로 에셋 없이 작동합니다. 별도 이미지·음원을 적용할 때는 `ASSET_PROMPTS.md`의 파일명과 프롬프트를 사용하세요.

## 규칙 구현 메모

- 게임판은 10×8입니다.
- 자신의 차례에 자기 말 하나를 8방향으로 한 칸 이동하거나 90도 회전합니다.
- 레이저는 이동할 수 없고, 판 바깥을 향하도록 회전할 수 없습니다.
- 행동 확정 후 자기 레이저가 자동 발사됩니다.
- 스플리터는 직진 레이저를 유지하면서 반사 경로를 하나 추가합니다.
- 왕은 어느 방향에서 맞아도 제거됩니다.
- 세모기사와 네모기사는 거울면에서 반사하고 비거울면에서 맞으면 제거됩니다.

초기 배치는 방송 규칙의 말 개수에 맞춰 대칭형 학급용 프리셋으로 구성했습니다. 방송 소품과 완전히 동일한 칸 배치가 필요하면 `initialPieces()`만 교체하면 됩니다.
