# 레이저 장기: 클래스 아레나

한 대의 태블릿에서 두 학생이 대전하고, 경기 시작·연결 상태·종료 결과만 교사 호스트에 전달하는 백엔드리스 학급용 게임입니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

GitHub에 업로드한 뒤 Vercel에서 프로젝트를 가져오면 됩니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다.

## 접속 흐름

1. 교사가 메인 화면에서 `교사 운영 페이지`에 접속합니다.
2. 학생 명단을 줄바꿈으로 등록하고 운영을 시작합니다.
3. 학생 태블릿에서 QR을 읽고 경기장 번호를 선택합니다.
4. 두 학생이 이름을 선택하면 호스트가 중복 참가 여부를 검사합니다.
5. 경기 시작 후 모든 말 이동과 레이저 계산은 태블릿 로컬에서 처리됩니다.
6. 왕이 제거되면 승자·패자·경기 시간·턴 수가 호스트에 전송되고 전광판에 반영됩니다.
7. 운영 종료 후 `경기 결과/과정 복사하기`를 누르고 한셀·엑셀에 붙여넣어 결과와 턴별 진행 과정을 확인합니다.

## 데이터 정책

- 데이터베이스가 없습니다.
- 교사 기록은 `sessionStorage`에만 임시 저장되어 탭을 닫으면 사라집니다.
- 학생 게임판은 새로고침 복구를 위해 해당 태블릿의 `localStorage`에만 저장됩니다.
- PeerJS 공용 시그널링은 연결 수립에만 사용하며 경기 기록을 저장하지 않습니다.
- 경기 결과 복사 내용은 탭으로 구분되어 한셀·엑셀의 각 열에 자동으로 나뉩니다.

## 이미지·효과음·BGM

- 버튼, 확인, 오류, 말 선택·이동·회전, 경기 시작, 레이저, 반사, 분리, 말 제거, 왕 피격, 승리, 결과 전송 효과음 14개가 `public/audio`에 포함되어 있습니다.
- 첨부 에셋의 레이저 발사·스플리터·승리 효과음이 적용되었고, 나머지 효과음은 `scripts/generate-sfx.mjs`로 다시 생성할 수 있습니다.
- 첨부된 교사 운영용 BGM이 `public/audio/host-bgm.mp3`에 포함되어 있으며 운영 시작 시 재생되고 운영 종료 시 정지합니다.
- 교사 화면에서 BGM 재생·일시정지·볼륨을 조절할 수 있습니다.
- 청색·적색 각 5종의 실제 플레이용 탑뷰 말 이미지가 이동과 90도 회전에 연결되어 있습니다.
- 메인 문양, 승리 왕관, 경기장·호스트·결과·전광판 배경이 화면별로 적용되어 있습니다.
- 이미지와 음원 교체용 프롬프트는 `ASSET_PROMPTS.md`에 있습니다.

## 규칙 구현 메모

- 게임판은 모든 칸이 정사각형인 8×8 정사각형입니다.
- 장기판 좌우에는 서로 마주 보는 두 플레이어 전용 정보 패널이 있으며, 게임 시간·현재 전적·턴별 진행 로그·제거된 말을 표시합니다.
- 자신의 차례에 자기 말 하나를 8방향으로 한 칸 이동하거나 90도 회전합니다.
- 레이저는 이동할 수 없고, 판 바깥을 향하도록 회전할 수 없습니다.
- 행동 확정 후 자기 레이저가 자동 발사됩니다.
- 스플리터는 직진 레이저를 유지하면서 반사 경로를 하나 추가합니다.
- 왕은 어느 방향에서 맞아도 제거됩니다.
- 세모기사와 네모기사는 거울면에서 반사하고 비거울면에서 맞으면 제거됩니다.

초기 배치는 사용자가 제공한 8×8 기준 이미지에 맞춰 밝은색 진영을 적색 플레이어에, 어두운색 진영을 청색 플레이어에 대응시켰습니다. 위치뿐 아니라 레이저 발사구와 각 거울면의 방향도 함께 반영했습니다.
